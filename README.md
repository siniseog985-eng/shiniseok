# SIS STUDIO

SIS STUDIO is a personal music workspace PWA.

## Deploy to a new GitHub repository
1. Create a new repository.
2. Upload every file in this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. Open the published HTTPS URL. On iPhone, use Safari Share → Add to Home Screen to install.

## Included
- `index.html` — app interface and interactions
- `manifest.json` — PWA metadata and app name
- `sw.js` — app-shell caching
- `icon-192.png`, `icon-512.png` — app icons
- `.nojekyll` — GitHub Pages helper

The app branding is **SIS STUDIO**. The existing dark visual style and player features are retained. Audio format support depends on the browser; FLAC playback may vary by device. Test on the target iPhone after deployment.
